# Connect a Radio

1. Set the radio's core address:
    - for a 4G radio (eNB), the MME address: Ella MOCN's `s1.address`, port 36412;
    - for a 5G radio (gNB), the AMF address: Ella MOCN's `ng.address`, port 38412.
2. Broadcast at least one PLMN of an operator that has MMEs (4G) or AMFs (5G).
3. In **Radios**, check that the radio's status is **Up**.
