# Check Whether an MME Is Overloaded

1. In **Operators**, open the operator.
2. In **Core network nodes**, read the **Overload** column of the MME. **None** means the MME is not overloaded. Otherwise it shows the traffic the radios reject for that MME.
3. Hover the value to see the GUMMEIs it applies to.
