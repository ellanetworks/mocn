# Check Whether an MME or AMF Is Overloaded

1. In **Operators**, open the operator.
2. In **Core network nodes**, read the **Overload** column of the MME or AMF. **None** means the node is not overloaded. Otherwise it shows the traffic the node asked to reject.
3. Hover the value to see the GUMMEIs (MME) or the slices (AMF) it applies to.
